# Код финального APK

Манифест, ресурсы и smali пакета ru.localscribe извлечены из опубликованного LocalScribe.apk (0.9.3-dev / 23, UX1). Оригинальный APK сохранён без изменений.

Полный гайд и сведения о составе исходников — в [README](../../README.md).

Для сборки восстановленного кода используйте [инструкцию](../../docs/RECOVERED_BUILD.md) и `src/tools/rebuild_recovered.py`. Полный байткод зависимостей, модели и нативные библиотеки берутся из APK финальной версии; smali приложения накладывается из этого каталога.
