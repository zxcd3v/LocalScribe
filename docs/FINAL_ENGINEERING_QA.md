## Данные, миграция и восстановление

Схема SQLite повышена с исходной 3 до **6**. Миграция backfill сохраняет payload, добавляя `end_ms` и `status`; создаёт `processing_runs`, `processing_segments`, `processing_speakers` и отдельную `notes`. Обход старых payload ограничен порциями. Staging удаляется вместе с recording через FK; метаданные записи обновляются без REPLACE родительской строки. Ручные исправленные сегменты защищены при promotion; конспекты не заменяются автоматическим текстовым редактором.

Резервные копии перед изменениями: `.codex-backup/build/`, `.codex-backup/pipeline/`, `.codex-backup/storage-audit/`. Сохранены исходные код/конфиги, а не повторные гигабайтные копии моделей/APK. Git отсутствует и не требовался. Резервная копия кода не заменяет резервную копию пользовательского хранилища перед установкой обновления. Миграция на настоящем устройстве и обновление с подписью владельца ещё не подтверждены; ключ владельца в комплект не включён.

## Оставшиеся ограничения

- **Нет новых измеренных WER/CER/DER/JER/ошибок границ/RTF/peak RSS-PSS/времени импорта и экспорта.** `tools/score_transcript.py` - офлайн-счётчик по проверенным TSV, не inference. DER: zero collar, overlap включён, оптимальная глобальная перестановка. WER требует согласованного порядка текста при одновременных репликах; произвольные speaker ID не должны определять эталонный порядок.
- Нет измеренного сравнения GigaAM и альтернативных Android-конфигураций Whisper на одном целевом корпусе. Модель не заменялась по неподтверждённому преимуществу.
- Текущая поставка включает исходники основных модулей и native dependencies, но **не полный исходный код оригинального integration DEX**. Его повторное присоединение не доказывает source-reproducible внутренний audio capture.
- Для PLDA/VBx весов отдельная полнота атрибуции не установлена; перед публикацией проверить происхождение каждой матрицы. Наличие лицензии библиотеки не устанавливает лицензию всех её весов.
- Overlap separator рассчитан на два источника. Не гарантируются три одновременно говорящих, точное число похожих голосов или безошибочная идентификация личности. ASR token emission не является forced alignment слов.
- Пять presets имеют реальные параметры, но названия не означают доказанное улучшение точности. Шумоподавление и GPU/NNAPI/NPU не добавлены без измерений.
- Исходный APK около 1,886 GiB остаётся неизменённым. Новый release/debug/full/no-Qwen размер, подпись, zipalign и установка должны быть записаны по готовым файлам. Публикация не выполнялась.

## Финальный статус

Этап **не объявлен полностью принятым**: ожидаются итог текущей сборки/app-тестов, полный model-прогон после исправления Windows runtime и проверки устройства из матрицы. Непроведённые сценарии не отмечены успешными. Текущие инженерные исправления, резервные копии и отчёты доступны локально.
