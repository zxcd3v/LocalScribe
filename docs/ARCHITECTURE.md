# Архитектура

Kotlin / Jetpack Compose: интерфейс и навигация. Модули Gradle: app, core, analysis, ort. Локальное хранилище сохраняет записи, реплики, участников и конспекты. ONNX Runtime, sherpa-onnx и JNI выполняют распознавание и анализ на CPU устройства.

Путь данных: локальный файл или микрофон → декодирование аудио → VAD → STT → диаризация → реплики с временными метками → просмотр, воспроизведение и JSON.

Русский STT: GigaAM v3; потоковый вариант: T-one; английский: Whisper Tiny. VAD: Silero. Диаризация: Nemotron и дополнительные pyannote/WeSpeaker/VBx. Подробные файлы, размеры и лицензии перечислены в MODEL_INVENTORY.md; notices сохранены в src/licenses/.

Облачная обработка не требуется. Задача относится к STT. Найденная поставка содержит необязательный локальный текстовый редактор Qwen; это отдельная возможность, не механизм распознавания речи и не обязательная часть задачи.
