## Проверка без интернета

1. Заранее скачать APK и тестовые аудиофайлы на телефон.
2. Установить APK. До первого запуска включить авиарежим, убедиться, что Wi-Fi отключён.
3. Открыть приложение и дождаться локальной подготовки встроенных моделей.
4. Импортировать тестовый файл из локального хранилища, запустить обработку.
5. Проверить текст, участников, временные метки и воспроизведение.
6. Сохранить JSON в локальную папку. Повторить для остальных записей.

Системный файловый диалог может показывать облачные провайдеры: для этой проверки нужно выбирать файлы, уже сохранённые на устройстве.

## Формат экспорта

```json
{
  "transcript": [
    {
      "speaker_id": "speaker_1",
      "start_ms": 1250,
      "end_ms": 4380,
      "text": "Добрый день!"
    }
  ]
}
```

`transcript` — массив реплик; `speaker_id` и `text` — строки; `start_ms` и `end_ms` — целые числа в миллисекундах. Пример иллюстрирует формат и не является результатом тестирования.

## Критерии оценки

| Критерий | Баллы |
|---|---:|
| Точность транскрибации | 40 |
| Точность диаризации | 25 |
| Точность временных меток | 10 |
| Скорость обработки | 10 |
| Работоспособность и UX | 10 |
| Защита решения | 5 |

Приоритет подготовки — проверка текста, участников и временных меток на реальных разговорах: вместе эти критерии дают 75 баллов. В качестве основного компонента распознавания используется локальный STT. Упоминание LLM в задании уточнено командой как опечатка; необязательный Qwen не заменяет STT.
