# Установка и использование

Android 8.0+, достаточно свободного места для APK около 2 ГБ и распаковки моделей. Скачайте APK из Releases. Разрешите установку из выбранного файлового менеджера и установите приложение.

UX1 подписан отдельным ключом. Обновление поверх сборки с другой подписью невозможно. Перед самостоятельным удалением старой установки экспортируйте важные данные. Автоматически приложение и данные не удаляются.

Выключите Wi-Fi и мобильные данные до запуска. Модели находятся внутри полной сборки и подготавливаются локально. Импортируйте WAV/MP3/M4A/MP4 или запишите микрофон, затем нажмите «Обработать запись». После обработки доступны реплики, участники, таймкоды, воспроизведение и конспект. Экспорт JSON сохраняется через системный выбор файла.

Плавающая кнопка требует разрешения на отображение поверх приложений. Системное аудио доступно с Android 10 и только для приложений, разрешающих захват. Микрофон может быть занят другим приложением.
