# Модели и лицензии

Полная сборка содержит локальные модели. Для распознавания и диаризации сеть не требуется. Инференс выполняется через ONNX Runtime, sherpa-onnx и JNI на CPU устройства.

| Компонент | Модель | Лицензия по поставленным уведомлениям |
|---|---|---|
| Русская речь | GigaAM v3 E2E RNN-T, encoder INT8 | MIT |
| Потоковая речь | T-one CTC | Apache-2.0 |
| Английская речь | Whisper Tiny | MIT |
| Активность речи | Silero VAD | MIT |
| Основная диаризация | Nemotron | OpenMDW-1.1 |
| Вектор голоса | WeSpeaker ResNet34 | CC BY 4.0 |
| Сегментация речи | pyannote 3.0 | MIT |
| Уточнение диаризации | speakrs / VBx | Apache-2.0 для speakrs; см. notices для весов |
| Разделение двух голосов | MossFormer2 | Apache-2.0 |
| Эмоциональная окраска | GigaAM-Emo | MIT |
| Дополнительный текстовый редактор | Qwen3-0.6B Q8 | Apache-2.0 |

Qwen используется отдельно от STT. Для получения текста речи LLM не требуется.

Состав и контрольные суммы файлов: `config/models.lock.json`, `config/extra-models.lock.json`. Лицензии библиотек и моделей: `src/licenses/`, лицензии поставщиков — в `src/vendor-sources/`. Уведомления и атрибуция сохраняются при распространении. Происхождение отдельных матриц PLDA не установлено в имеющемся комплекте; это остаётся ограничением документации лицензий.
