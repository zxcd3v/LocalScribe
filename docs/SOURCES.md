# Исходники и выпуск UX1

Готовый APK: LocalScribe 0.9.3-dev, versionCode 23, UX1. Проверен владельцем. Приложение при подготовке публикации не пересобиралось и не изменялось.

`src/` содержит имеющийся Gradle-проект и исходники модулей app, core, analysis, ort, нативные зависимости и лицензии. Этот проект указывает версию 0.8.6; полное соответствие финальному 0.9.3 не установлено. Нельзя выдавать его за воспроизводимый исходный проект финального APK.

`src/ux1/` содержит Java-помощники и изменённые smali-классы пяти UX-изменений финальной сборки. Патч выполнен поверх APK 0.9.3-dev. Полный исходный проект этой бинарной основы в найденных материалах отсутствует.

Модели уже встроены в финальный APK. Большие бинарные материалы публикуются через Releases. Конфигурации моделей: `config/`; исходные Gradle-пути и lock-файлы сохранены внутри `src/`.

Локальные ключи подписи, пароли, промпты, кэши и журналы в публикацию не включены. Для собственной сборки задайте Android SDK в локальном `src/local.properties`; используйте собственный ключ. Готовый APK предназначен для проверки продукта.
