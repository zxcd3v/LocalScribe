# Исходники

`src/` сохраняет Gradle-структуру модулей app, core, analysis, ort и необходимые нативные зависимости. Версия найденного Gradle-проекта — 0.8.6. Полный исходный проект бинарной основы 0.9.3 отсутствует; воспроизводимость финального APK не подтверждена.

`src/ux1/` содержит Java-помощники и изменённые smali-классы UX1 поверх APK 0.9.3-dev: прогресс и ETA, автопрокрутка, переключатель плавающей кнопки, обновление результата и действие обработки записи.

Финальный APK публикуется без пересборки. Модели встроены. Конфигурации моделей находятся в config/ и продублированы в src/ для сохранения Gradle-путей. Лицензии и уведомления сохранены в src/licenses/ и vendor-sources/.

Для собственной сборки укажите Android SDK в src/local.properties и собственный ключ подписи. Ключи и пароли не публикуются.
